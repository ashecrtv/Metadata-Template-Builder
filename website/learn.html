Photo metadata, explained

A photo nobody can find doesn't exist

Metadata is the text that travels inside every image file: who's in it, where and when it was taken, who shot it and who owns it. With it, a picture can be found, credited and published in seconds. Without it, it's just a file name like DSC_4821.JPG, and a photo nobody can find isn't worth anything to anyone.

Why it matters, even if you never touch a camera

Found in seconds

A social team searching "Tyrone Tracy touchdown" gets the frame immediately, not after scrolling through a cluttered gallery. The best photo is the one you can find, and nobody loses an afternoon hunting for it.

Requests filled fast

When marketing, partnerships or the front office asks for "every photo of the honoree," it's one search. A single frame or a full gallery to pick from goes out the same day.

Photos that earn more

Keywords and captions are what search engines and ad platforms read. Tagged images get placed in front of the right audience and keep working after the post goes up.

Credit and rights travel with the file

The photographer, the client and the copyright stay attached when the file is emailed, uploaded or reposted. Fewer uncredited images, clearer licensing.

One way of naming things

A shared template means every photographer captions the same way: same spelling of names, same event titles, same keywords. That order is what keeps a library searchable across seasons.

Ready for any system

Standard IPTC and XMP fields carry over cleanly into a DAM, a cloud drive or a team's upload tools, so the archive stays organized wherever the files end up.

How this site works

  1. Booking. A client fills out the booking form. You get an email with a link that holds every detail.
  2. Builder. The link opens the builder already filled in. For games it pulls both teams and rosters from ESPN. You check the caption and confirm.
  3. Template + file name. The builder makes a Photo Mechanic metadata template (.XMP), a code replacement file and an ingest file name. Tick several games to make a whole season at once.
  4. Job board. The template and file name are saved on the job, so on shoot day everything is in one place.

Photo Mechanic, step by step

Photo Mechanic by Camera Bits is the ingest and captioning tool most sports and news photographers use. Full documentation: docs.camerabits.com.

1. Load the metadata template

Image ▸ Metadata Template… ▸ Load, and pick the .XMP from the builder. Then, in the Ingest window, tick Apply IPTC/XMP template so every photo gets it as it comes off the card.

2. Rename on ingest

In the Ingest window, tick Rename photos as and paste the builder's file name, for example 20260611_WSLAM_NYvsATL_AG_. Turn on Sequence; the name ends in "_" so Photo Mechanic adds the number.

3. Load the code replacements

Image ▸ Code Replacements… ▸ load the .txt. Then typing /a10/ in a caption becomes the player's full name, number and team. Set the delimiter to match the builder (default /).

4. Caption the action

The template already holds the dateline, venue and credit. You type only who and what: /a10/ scores a touchdown. Photo Mechanic expands the code when you leave the field.
