Step 4

Download

Load these into Photo Mechanic: the metadata template on ingest, the code file under Code Replacements, and the Structured Keywords list if you like clicking names.

Metadata template

Image ▸ Metadata Template… ▸ Load, then apply it on ingest. Sets the caption, headline, event, place, credit, copyright and keywords.

Ingest file name

Ingest ▸ Rename as: YYYYMMDD_CLIENT_AWAYvsHOME_INITIALS_{sequence}

Click to edit. It ends with "_" so Photo Mechanic can add its own sequence number (turn on Sequence in Ingest → Rename).
